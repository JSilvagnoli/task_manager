# Task Manager

A command-line task management application written in Python. Users can create, update, search, sort, and manage tasks with persistent JSON storage. This project was built to practice core Python fundamentals, modular program design, file handling with JSON, program organization, and automated testing.

## User Features

- View all tasks
- Add new tasks
- Update task details
- Delete existing tasks
- Search tasks by keyword
- Sort tasks
- Display task statistics
- Assign priorities and categories
- Add due dates
- Save tasks to JSON
- Load tasks from JSON
- Menu-driven command-line interface

## Testing

- Unit tests
- Integration tests

## Technologies

- Python 3
- JSON
- unittest

## Concepts Practiced

- Object-oriented programming
- Modular program design
- Data structures and algorithms
- File persistence and JSON serialization
- Input validation
- Program state management
- Error handling
- Unit testing and integration testing
- Refactoring and code organization

## Running the Project

Clone the repository and run:

```bash
python main.py
```

## Running Tests

```bash
python -m unittest test_task.py
python -m unittest test_task_manager.py
python -m unittest test_storage.py
python -m unittest test_integration.py
```
