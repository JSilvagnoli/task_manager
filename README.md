# Task Manager

A command-line task management application written in Python. This project was built to practice core Python concepts including functions, data structures, file persistence with JSON, and program organization.

## Features

- View all tasks
- Add new tasks
- Update task completion status
- Delete existing tasks
- Search tasks by keyword
- Display task statistics
- Save tasks to a JSON file
- Load tasks from a JSON file
- Menu-driven command-line interface

## Technologies

- Python 3
- JSON
- Regular Expressions (for task searching)

## Concepts Practiced

- Functions
- Lists and Dictionaries
- Loops
- User Input
- File I/O
- JSON Serialization
- Program State Management
- Basic Refactoring

## Future Improvements

- Task priorities

- Due dates
- Task sorting
- SQLite database support

- REST API using FastAPI
- Web frontend

Clone the repository and run:

```bash
python main.py
```
